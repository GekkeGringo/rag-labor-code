# Решения по проекту

## Источник и парсинг
- Источник: docx с текстом ТК РФ (редакция с изменениями до закона от 06.04.2024 N 70-ФЗ). Выбран docx, потому что абзацы в нем целые и не нужна склейка рваных строк, как в txt.
- Сырой текст не хранится в git (папка data/ в .gitignore).
- Вырезаем: пометки «(в ред. ...)», редакторские справки «Действие ... распространяется на правоотношения...», подпись под кодексом, утратившие силу статьи (85, 175, 351.2, 360).
- Оставляем: ссылки на другие законы внутри текста статей и статью 422 (перечень утративших силу законов).
- Номера статей хранятся строками (бывают 5.1 и 348.11-1).
- Результат: 524 статьи, 0 дублей номеров.

## Чанкинг
- В каждый чанк добавляется заголовок статьи, чтобы фрагмент не терял контекст.
- Замеры: статья целиком даёт 131 из 524 чанков длиннее 2000 символов (максимум 11920), хвост такой статьи эмбеддинг-модель может обрезать. Поэтому «статья целиком» остаётся только как baseline.
- Кандидаты: до 1500 символов (840 чанков) и до 800 символов (1328 чанков). Выбор делаем по Recall@k на dev-вопросах, не раньше.
## Gold set
- Вопросы q01-q50 написаны мной самостоятельно.
- Gold set разделён на dev (~60%) и test (~40%) скриптом со стратификацией по типу вопроса, seed 42. Все настройки подбираются только на dev, test смотрим один раз в конце.
